# Локальный стенд практики

Это **симулятор** платформы практики для быстрой проверки сценариев без Telegram-токенов.

Внутри:

- три бота: «Запись к мастеру», «Умный консультант», «Витрина товаров»;
- конструктор брифов — те же 4–5 вопросов, что будет задавать бот-платформа;
- чат с кнопками, картинками, корзиной и заявками;
- «Мои боты» и просмотр брифа.

## Запуск

Из корня `school-funnel`:

```powershell
python -m uvicorn local_practice.app:app --host 127.0.0.1 --port 8090
```

Или двойным кликом:

```text
local_practice\start.ps1
```

Открыть:

```text
http://127.0.0.1:8090
```

## Что проверить

1. **Запись**: услуга → имя → телефон → дата → время → подтверждение. В конце появится «уведомление мастеру».
2. **AI-консультант**: вопрос про опоздание → ответ по правилам; вопрос не из базы → передача человеку.
3. **Витрина**: категория → товар с фото → корзина → оформление → «уведомление магазину».
4. **Бриф**: «+» → выбрать шаблон → изменить поля → собрать нового бота.

Демо-боты создаются автоматически при первом открытии. Всё живёт в памяти процесса: перезапуск — чистый стенд.

## Важно

Это не Telegram. Здесь проверяется **логика и UX**, а не вебхуки, токены и хранение.

Для реального Telegram-теста нужны 4 токена из @BotFather:

- платформа-конструктор;
- бот записи;
- AI-бот;
- бот-витрина.

После них этот же сценарий переносится в Telegram-бота платформы по ТЗ.
