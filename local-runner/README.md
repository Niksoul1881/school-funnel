# Local runner (MVP)

Маленький процесс на вашем ПК. Подключается к платформе по pairing-коду и даёт браузерный терминал в выбранной папке.

## Запуск

Требуется Node.js 22+ (он уже есть, если установлен DSH).

1. Откройте **Профиль → Мой компьютер → Подключить компьютер**.
2. Скопируйте команду вида:

```powershell
node local-runner/runner.mjs --server https://school.91-184-242-178.sslip.io:8443 --code 123456 --dir "C:\Users\NikSouk\Desktop\Proj\school-funnel"
```

3. Запустите её в папке проекта.
4. В профиле появится компьютер со статусом **online**, кнопка **Терминал**.
5. Дальше запускать можно без `--code`:

```powershell
node local-runner/runner.mjs --dir "C:\Users\NikSouk\Desktop\Proj\school-funnel"
```

Токен хранится в `local-runner/.device.json` (в git не попадает).

## Ограничения MVP

- Пока это только терминал.
- Команды выполняются с правами вашего пользователя.
- Подтверждения опасных команд ещё не включены.
- Файловый редактор и локальный DSH — следующий шаг.
