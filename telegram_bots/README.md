# Четыре Telegram-бота для теста

- **platform** — главный бот-конструктор: выбор шаблона, бриф, токен, запуск бота ученика.
- **booking / ai / shop** — три готовых бота ученика для проверки сценариев.

## 1. Создай четыре бота

В Telegram открой **@BotFather** → `/newbot` четыре раза:

```text
platform_test_твой_ник_bot
booking_test_твой_ник_bot
ai_test_твой_ник_bot
shop_test_твой_ник_bot
```

## 2. Заполни токены

Открой:

```text
private/telegram-test.env
```

Вставь:

```env
PLATFORM_BOT_TOKEN=...
OWNER_TG_ID=...
BOOKING_BOT_TOKEN=...
AI_BOT_TOKEN=...
SHOP_BOT_TOKEN=...
```

`OWNER_TG_ID` — твой ID из **@userinfobot**. Туда будут приходить записи и заказы.

`LLM_API_KEY` можно оставить пустым — AI-бот будет отвечать по FAQ. С ключом он отвечает через нейросеть.

## 3. Запусти

Три готовых бота:

```powershell
python telegram_bots\launch.py
```

Главный бот-конструктор — отдельным окном:

```powershell
python telegram_bots\platform_bot.py
```

Главный бот проведёт: шаблон → 4–5 вопросов → токен нового бота → запуск.
Токен для нового бота берётся в BotFather; он не должен совпадать с уже запущенными.

## 4. Проверь

Открой каждого бота и нажми `/start`:

- **platform** — «Собрать бота», выбрать шаблон, заполнить бриф;
- **booking** — услуга, имя, телефон, дата, время;
- **ai** — вопрос про опоздание;
- **shop** — товар, корзина, заказ.

Заявка/заказ придут тебе в Telegram от имени соответствующего бота.

## Остановить

`Ctrl+C` в окне запуска.

## Важно

- Это polling, без вебхуков — для локального теста.
- Токены лежат в `private/`, в git не попадают.
- После теста отзови токены в BotFather.
