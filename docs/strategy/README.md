## Коротко

- **Продукт:** школа + платформа. Ученик заходит в браузер, собирает бота / агента / мини-апп по брифу и запускает в Telegram. Без установки, VPN и API-ключей.
- **Три направления:** чат-боты (5–60 тыс. ₽), AI-агенты (15–60 тыс. ₽), мини-приложения (20–50 тыс. ₽+).
- **Воронка:** трафик → бот → 2 статьи → тест-драйв 48 часов (5 уроков + финал) → анкета → разбор → курс → подписка.
- **Технология:** DeepSeek Harness (DSH, MIT) как агентный рантайм + свой model gateway + контейнер на проект. DSH даёт сессии, песочницу, инструменты и headless-режим; платформа добавляет авторизацию, биллинг, LMS и деплой.
- **Экономика:** курс 49,9–129,9 тыс. ₽, подписка 1 990 ₽/мес, хостинг 490–690 ₽/мес. Валовая маржа курса ~65%, подписки ~54%, LTV/CAC ~6,5–7,6×.
- **Роудмап:** прототип — ноябрь 2026, MVP — декабрь, первый платный поток — январь 2027, масштабирование — февраль–июнь 2027.

## Что нужно решить

1. Название и бренд.
2. Цена курса и подписки.
3. Модель доступа к API: наш ключ с квотой, BYOK или гибрид.
4. Юрлицо, платежи, 152-ФЗ.
5. Хостинг и хранение данных.
6. Дата и размер первого потока.
7. Техлид платформы.
8. Три шаблона MVP: бот-визитка, AI-ассистент, витрина.
