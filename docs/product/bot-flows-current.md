# Текущие схемы ботов

Документ фиксирует **как сейчас реально работают боты**. Тексты сообщений пока живут в коде, но у каждого этапа есть ключ — по нему можно писать новый текст и потом перенести его в `content.json` / шаблон.

## 1. Онбординг на платформе

```text
/start
  → приветствие + картинка меню
  → три кнопки: Студия красоты / Витрина / Подарок
  → выбран шаблон
  → 5 шагов брифа
  → BotFather: имя и username
  → токен
  → создание бота
  → успех: ссылка на бота + кабинет
```

### Студия красоты: 5 шагов

| # | Ключ | Что спрашиваем | Пример |
|---|---|---|---|
| 1 | `beauty.name` | Название | Marina Beauty Space |
| 2 | `beauty.services` | Услуги через запятую | Стрижка, Окрашивание, Маникюр |
| 3 | `beauty.details` | Описание и цены | Стрижка — от 2500 ₽, 1.5 часа |
| 4 | `beauty.slots` | Свободные окошки | 12:00, 15:30, 19:00 |
| 5 | `beauty.contact` | Контакт | @admin |

На каждом шаге:

- пример;
- «🎓 Совет профи»;
- кнопка «🪄 Оставить готовый шаблон».

### Витрина товаров

| # | Ключ | Что спрашиваем |
|---|---|---|
| 1 | `shop.name` | Название магазина |
| 2 | `shop.products` | Товары: фото → название/цена/описание/категория |
| 3 | `shop.delivery` | Доставка или самовывоз |
| 4 | `shop.contact` | Контакт |
| 5 | `shop.payment` | Ссылка на оплату (можно пропустить) |

### Подарок за подписку

| # | Ключ | Что спрашиваем |
|---|---|---|
| 1 | `gift.name` | Название проекта |
| 2 | `gift.channel` | Канал для подписки |
| 3 | `gift.gift` | Что дарим |
| 4 | `gift.contact` | Контакт |

### Финал онбординга

| Ключ | Смысл |
|---|---|
| `platform.botfather` | Инструкция: @BotFather → /newbot → имя → username → токен |
| `platform.token` | Приём токена |
| `platform.building` | «Собираю бота…» |
| `platform.success` | Ссылка на бота, ссылка в кабинет, фраза про 15 000 ₽ |

## 2. Клиентский бот «Студия красоты»

```text
/start
  → приветствие + адрес (если есть)
  → выбор услуги
  → выбор даты (7 дней)
  → выбор времени
  → имя
  → телефон
  → подтверждение
  → запись создана
  → уведомление владельцу
```

### Этапы и ключи

| Этап | Ключ | Сейчас показывает |
|---|---|---|
| Старт | `beauty.start` | Приветствие + услуги |
| Услуга | `beauty.service` | Кнопки «Услуга · цена» |
| Дата | `beauty.date` | Сегодня/завтра + 5 дат с днём недели |
| Время | `beauty.time` | Только свободные и будущие слоты |
| Имя | `beauty.name_prompt` | «Как вас зовут?» |
| Телефон | `beauty.phone` | «Оставьте телефон» |
| Подтверждение | `beauty.confirm` | Услуга, дата, время, имя, телефон |
| Успех | `beauty.done` | «Вы записаны», перенести/отменить |
| Владельцу | `beauty.owner_new` | Новая заявка с контактами |
| Отмена | `beauty.cancel` | Уведомление владельцу |

### Ветки

- «Перенести» → снова выбор даты, услуга и контакты сохраняются.
- «Отменить» → слот освобождается, владельцу уходит уведомление.
- Занятый слот → показывает только свободные.
- Прошедшее время сегодня → скрыто.
- Несуществующее время → не пускает дальше, остаётся на шаге времени.

## 3. Клиентский бот «Витрина товаров»

```text
/start
  → приветствие
  → категории / хиты
  → карточка товара
  → добавить в корзину
  → корзина: количество / удалить
  → оформление: имя
  → телефон
  → доставка или самовывоз
  → заказ ORD-XXXXXX
  → ссылка на оплату (если есть)
  → уведомление владельцу
```

### Этапы и ключи

| Этап | Ключ | Сейчас показывает |
|---|---|---|
| Старт | `shop.start` | Каталог и хиты |
| Категории | `shop.categories` | Все / категории |
| Карточка | `shop.product` | Фото, цена, описание |
| Корзина | `shop.cart` | Позиции, количество, итог |
| Имя | `shop.name_prompt` | Как вас зовут |
| Телефон | `shop.phone` | Телефон |
| Доставка | `shop.delivery_prompt` | Самовывоз / доставка |
| Заказ | `shop.order_done` | Номер заказа и итог |
| Оплата | `shop.payment` | Ссылка на оплату, если задана |
| Владельцу | `shop.owner_new` | Новый заказ |

## 4. Клиентский бот «Подарок за подписку»

```text
/start
  → приветствие
  → кнопка «Подписаться»
  → проверка подписки
  → подарок
  → уведомление владельцу
```

### Этапы и ключи

| Этап | Ключ | Сейчас показывает |
|---|---|---|
| Старт | `gift.start` | Приветствие и подписка |
| Подписка | `gift.subscribe` | Ссылка на канал |
| Проверка | `gift.check` | Проверяет подписку |
| Подарок | `gift.done` | Выдаёт подарок |
| Владельцу | `gift.owner_new` | Кто получил подарок |

## 5. Где менять тексты

Сейчас:

- `telegram_bots/platform_bot.py` — онбординг, шаги, BotFather, успех;
- `local_practice/engine.py` — клиентские сценарии и тексты этапов;
- `platform/app/catalog.py` — стартовый `content.json` проекта.

Правильная цель — вынести все тексты в `content.json` по ключам из таблиц выше. Пока ключи — это карта для переноса, а не готовый редактор.

## 6. Miro

Точные пошаговые схемы двух клиентских ботов:

- `gift-flow.pdf` — «Подарок за подписку»;
- `shop-flow.pdf` — «Витрина товаров · кондитерская».

Общая схема всех ботов:

- `bot-flows.svg` — залить на доску как изображение;
- `bot-flows.pdf` — то же, если SVG не принимается;
- `bot-flows.mmd` — исходник Mermaid: можно вставить в Miro через приложение Mermaid и редактировать.
