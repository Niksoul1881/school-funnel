# Roadmap: из прототипа в коммерческий продукт

Текущее состояние: сильные сценарии и боты, но это ещё не SaaS. Ниже — что реально не хватает, в порядке влияния на продажи.

## Сейчас есть

| Блок | Статус |
|---|---|
| 3 бота: запись, подарок, витрина | ✅ работает |
| Брифы и запуск из Telegram | ✅ |
| Заявки/заказы владельцу | ✅ |
| `/stats`, `/orders` | ✅ |
| Календарь 7 дней, защита от двойной записи | ✅ |

| Хостинг 24/7 | ❌ локальный ПК |
| Платежи платформы | ❌ нет |

## P0 — без этого нельзя продавать за 20–40 тыс.

### 1. Хостинг 24/7 и вебхуки
Сейчас боты живут на локальном ПК. Если ПК выключен — бизнес клиента умер.
Нужно: VPS, webhook-режим, автозапуск, healthcheck, автоперезапуск.

### 2. Реальная оплата
Сейчас только ссылка. Нужно:
- ЮKassa / Tinkoff / Telegram Stars;
- создание платежа;
- подтверждение оплаты;
- чек/статус;
- возврат.

### 3. Фото end-to-end
Нужно: загрузка в Telegram → скачивание → S3/диск → сжатие → публичный URL → карточка в боте и вебе.
Сейчас фото сохраняется локально, веб-превью на сервере его не видит.

### 4. Напоминания и перенос записи
- напоминание за 24 ч и 2 ч;
- перенос без потери заявки;
- отмена;
- уведомление мастеру.

### 5. Веб-CRM
Кабинет владельца:
- список заявок/заказов;
- статусы: новая, подтверждена, выполнена, отменена;
- фильтры и экспорт CSV;
- карточка клиента.

## P1 — повышает чек и удержание

### 6. Интеграции
- Google Calendar;
- amoCRM / Bitrix24;
- webhooks;
- email/SMS.

### 7. Аналитика
- воронка: старт → услуга → дата → телефон → заявка;
- конверсия;
- выручка;
- drop-off по шагам.

### 8. Mini App
Витрина и запись внутри Telegram Mini App, а не только чат.

### 9. Мульти-мастер / филиалы
- несколько сотрудников;
- свои слоты;
- филиалы;
- роли.

### 10. Рассылки и дожимы
- сегменты;
- отложенные сообщения;
- брошенная корзина;
- реактивация.

## P2 — масштаб и white-label

- white-label для агентств;
- конструктор сценариев;
- AI-помощник для текстов;
- мобильная админка;
- SLA и статус-страница.

## Инфраструктура и юридика

- Postgres + Redis + очереди;
- бэкапы и восстановление;
- логи, метрики, алерты;
- rate limit и антиспам;
- 152-ФЗ, согласие на обработку, политика, удаление данных;
- оферта и чеки.

## Что беру следующим без вопросов

1. Напоминания + перенос/отмена записи.
2. Веб-CRM для заявок и заказов.
3. Фото end-to-end.
4. Хостинг 24/7 и вебхуки.
5. Оплата.

Дальше — интеграции и аналитика.
