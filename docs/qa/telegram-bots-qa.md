## Проверено

### Запись

- приветствие и кнопки услуг;
- услуга свободным текстом: «хочу стрижку»;
- дата: «завтра», текстовая дата;
- время: «15:00»;
- имя, телефон;
- отказ на короткий телефон;
- подтверждение текстом «да»;
- уведомление владельцу отдельным сообщением;
- клиент не видит служебное сообщение;
- «заново» сбрасывает этап, а не застревает.

### Подарок за подписку

- приветствие;
- URL-кнопка канала (не callback);
- кнопка «Я подписался»;
- выдача подарка;
- URL-кнопка «Забрать подарок»;
- уведомление владельцу.

### Витрина

- приветствие и категории;
- категория «Все»;
- фото товара в карточке;
- поиск «медовик»;
- добавление в корзину;
- корзина с итогом;
- очистка;
- checkout;
- отказ на плохой телефон;
- заказ и уведомление магазину;
- цены с `₽` во всех карточках.

### Брифы и визуал

- 3 активных шаблона, ровно;
- у каждого 4 поля;
- обязательные поля заполнены defaults;
- нет пустых label;
- нет placeholder-строк в брифах;
- обложки PNG > 30 КБ, 1200×488;
- каталог API отдаёт 3 шаблона;
- все обложки отдаются с сервера 200.

Скриншот: [`covers.png`](covers.png).

## Найденные и исправленные баги

1. **Цены витрины без валюты.** В категориях и карточках было `3 200`, а не `3 200 ₽`. Исправлено нормализацией цены в `create_bot`.
2. **В карточках категорий не было эмодзи.** Добавлено для единообразия с поиском.
3. **«Заново» в записи не сбрасывало stage.** Сообщение возвращало старт, но сессия оставалась в `confirm`. Исправлено.
4. **Дублирующий шаблон.** «Заявка» была тем же, что «Запись»; заменена на «Подарок за подписку».

## Ограничения

- Реальный Telegram UI не автоматизировался: после инцидента с фокусом окна это небезопасно. Проверка идёт на уровне сценариев, API и веба.
- Загрузка фото в витрину проверена по коду и структуре контента, но не end-to-end через живой Telegram-аплоад.
- Проверка подписки сделана через `getChatMember`: бот должен быть админом канала. Если проверка недоступна, подарок выдаётся с уведомлением владельцу; это fallback, не жёсткий gate.
- Визуал ботов проверен по обложкам; экран Telegram-чата не снимался.
