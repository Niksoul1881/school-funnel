Блок 1

Быстрый старт + фундамент

Понять, чем агент отличается от бота, настроить рабочее место и за первое занятие запустить своего AI-бота в Telegram.

Соответствует их блоку 1.

Темы занятий
  1. Чат-бот, AI-бот и AI-агент — в чём разница. Три живых примера: бот конкурса отзывов (кнопки и сценарии), AI-репетитор (отвечает нейросетью), AI-редакция (сама работает по расписанию). botMathnews_aggregator
  2. Как устроен агент: модель + инструменты + память + цикл. На схеме AI-редакции: сбор → кластеризация → черновик → модерация → публикация.
  3. Экосистема Claude. Web, Desktop, Claude Code в терминале и расширение для VS Code — когда что использовать.
  4. Установка и первый запуск. Claude Code CLI + расширение VS Code + Desktop, логин, проверка.
  5. Первая сессия. Базовые команды, как читать ответы и правки, как откатывать.
  6. Инструменты разработки: что выбрать. Claude Code, Codex, Cursor, IDE-расширения — сравнение под задачи.
  7. Промптинг, который работает. Роль, контекст, задача, ограничения + рассуждение по шагам. Разбор реальных системных промптов: «Профессор Квасич», AI-агроном, AI-консультант сообщества. Mathdachalampada
  8. Промптинг 2.0. Примеры в промпте (few-shot), мета-промпты, системные промпты; как держать единый «голос бренда» в постах. limon_news_bot
  9. +Выбор модели и цена ответа. Groq, DeepSeek, GPT, Claude, локальные модели: скорость, качество, стоимость; цепочка «если одна упала — отвечает другая». Math
  10. Антипаттерны: как не сжечь токены. Дневной лимит вызовов, кэш ответов, «Франкенштейн» из копипаста. news_aggregatorrep_ml

  3. Продвинутые техники Claude Code. Субагенты, хуки, фоновые задачи, свои команды.

  5. Skills, Rules, Hooks. Переиспользуемые расширения и автоматизация рабочих процессов.

  7. MCP, часть 1: подключение готовых серверов.
  8. MCP, часть 2: свой сервер. Разбор нашего коннектора, который даёт Claude доступ к архиву отчётов клиента. Hogita
